# Epic: Build and Deploy a Controlled AI Agent Workflow

## Epic Statement

As a learner, I want to design and demonstrate a Claude Code project that uses Skills, agents, and specialized subagents so that I can show I understand how to delegate software work safely and deploy a validated application to production.

## Final Desired Result

The learner can independently:

1. explain the project problem
2. define measurable acceptance criteria
3. use Claude Code in a repository
4. configure reusable Skills
5. configure specialized agents
6. delegate bounded work to subagents
7. review an AI-generated implementation plan
8. validate changes with testing and build evidence
9. authorize a production release
10. deploy to Vercel
11. verify the live application
12. defend the design during a live demo

## Essential Question

> How can we use AI agents to accelerate software development without giving them uncontrolled authority?

## Final Evidence

The Epic is complete when the learner presents:

- working source code using Prisma ORM, Google OAuth, and Vercel
- Prisma schema/setup and evidence of persistent feature data
- Google sign-in/sign-out and protected-access evidence
- `CLAUDE.md`
- reusable Skills
- agent definitions
- documented agent boundaries
- successful tests
- successful build
- implementation approval evidence
- deployment approval evidence
- live Vercel URL
- production verification evidence
- oral explanation of the architecture
