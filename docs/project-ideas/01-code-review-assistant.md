# Project 1 — AI Code Review Assistant

## Description

Build an AI-powered code review workflow using Claude Code. The system reviews a small application, identifies issues, recommends improvements, validates changes, and deploys the approved application to Vercel.

## Goals

- use Claude Code inside a real repository
- configure project instructions
- build a reusable Code Review Skill
- separate research, implementation, testing, and deployment responsibilities
- review AI-generated changes before accepting them
- validate the application before production deployment
- deploy and verify the application on Vercel

## Design your solution

- What components and agents does this project need, and why?
- What context and allowed actions will each agent have?
- How will work be delegated and results returned?
- Where will human approval be required, and how will you enforce it?
- How will you test success and failure cases?

Create your own architecture diagram and explain your decisions.
