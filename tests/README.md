# Tests

Create meaningful automated tests for your application using the framework you select.

Your Unit Testing Agent writes and runs unit tests for expected behavior, edge cases, and failures. Your Test Agent independently verifies the complete suite, build, and acceptance criteria.

Configure `npm run test:unit` for unit tests and `npm test` for every additional required suite. See [Testing and commit requirements](../docs/TESTING.md): all testing must pass before code commits through the installed hook.
